# 停止聊天消息 API 测试页面

## 概述

这是一个专门用于测试 `POST /api/chat-messages/[taskId]/stop` API 端点的测试页面。该页面提供了完整的用户界面来模拟聊天消息的发送和停止流程。

## 访问地址

```
http://localhost:3001/test/stop-message
```

## 功能特性

### 1. 完整的测试流程

- **消息发送**: 模拟正常的聊天消息发送流程
- **taskId 获取**: 自动获取消息发送时生成的 taskId
- **消息停止**: 测试停止 API 的调用和响应
- **状态监控**: 实时显示当前操作状态

### 2. 用户界面组件

#### 控制面板

- **会话ID输入框**: 输入测试用的会话ID，或输入 "new" 创建新会话
- **消息内容输入框**: 输入要发送的测试消息
- **发送消息按钮**: 开始发送消息并获取 taskId
- **停止消息按钮**: 调用停止 API 来中断消息生成
- **清空消息历史按钮**: 清空当前的消息记录

#### 状态显示面板

- **会话ID**: 当前使用的会话ID
- **任务ID**: 从消息发送 API 获取的 taskId
- **响应状态**: 是否正在响应消息
- **加载状态**: 是否正在加载

#### 消息历史

- **用户消息**: 显示发送的测试消息
- **助手响应**: 实时显示AI的响应内容
- **系统消息**: 显示操作状态和结果信息

#### API 监控

- **网络请求监控**: 实时监控所有 API 调用
- **请求详情**: 显示请求方法、URL、请求体和响应体
- **调用状态**: 显示HTTP状态码和响应时间
- **错误信息**: 显示网络错误和API错误

### 3. API 调用详情

#### 发送消息 API

```
POST /api/chat-messages
Content-Type: application/json

{
  "inputs": {},
  "query": "消息内容",
  "conversation_id": "会话ID或null",
  "response_mode": "streaming"
}
```

#### 停止消息 API

```
POST /api/chat-messages/[taskId]/stop
Content-Type: application/json

{
  "user": "abc-123"
}
```

## 使用方法

### 基本测试流程

1. **准备测试数据**
   - 在"会话ID"输入框中输入有效的会话ID，或输入 "new" 创建新会话
   - 在"消息内容"输入框中输入测试消息

2. **开始监控**
   - 点击 API 监控面板中的"开始监控"按钮
   - 这将开始记录所有的网络请求

3. **发送消息**
   - 点击"发送消息"按钮
   - 观察状态面板中的 taskId 获取情况
   - 查看消息历史中的实时响应

4. **测试停止功能**
   - 在消息响应过程中，点击"停止消息"按钮
   - 观察 API 监控中的停止请求
   - 确认消息响应是否立即停止

5. **查看结果**
   - 检查 API 监控中的请求和响应详情
   - 查看消息历史中的系统提示
   - 确认停止操作是否成功

## 调试和故障排除

### 浏览器开发者工具

1. **打开开发者工具**: 按 F12 或右键选择"检查"
2. **查看控制台**: 查看详细的日志信息和错误
3. **监控网络**: 在网络面板中查看所有HTTP请求
4. **检查响应**: 查看API的响应状态码和内容

### 常见问题

#### 问题 1: 无法获取 taskId

**症状**: 发送消息后状态面板中的 taskId 显示为"无"

**可能原因**:

- 消息发送API调用失败
- 后端服务未正常运行
- API响应格式不正确

**解决方法**:

1. 检查浏览器控制台是否有错误信息
2. 查看网络面板中的API调用状态
3. 确认后端服务正常运行
4. 检查API响应中是否包含 taskId

#### 问题 2: 停止按钮无法点击

**症状**: 停止按钮显示为灰色，无法点击

**可能原因**:

- 没有正在进行的消息响应
- taskId 未正确获取
- 消息已经完成响应

**解决方法**:

1. 确保在消息响应过程中点击停止按钮
2. 检查状态面板中的 taskId 是否存在
3. 使用较长的测试消息以确保有足够时间测试停止功能

#### 问题 3: 停止API调用失败

**症状**: 点击停止按钮后显示错误信息

**可能原因**:

- taskId 无效或已过期
- 后端停止API实现有问题
- 网络连接问题

**解决方法**:

1. 检查API监控中的停止请求详情
2. 查看响应状态码和错误信息
3. 确认 taskId 的有效性
4. 检查后端日志（如果可访问）

### 最佳实践

1. **使用长消息**: 使用较长的测试消息确保有足够时间测试停止功能
2. **监控网络**: 始终开启API监控来查看详细的请求信息
3. **检查控制台**: 定期查看浏览器控制台的日志和错误
4. **测试不同场景**: 测试正常停止、无效停止、重复停止等不同场景
5. **记录问题**: 遇到问题时记录详细的错误信息和复现步骤
